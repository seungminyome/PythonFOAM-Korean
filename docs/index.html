지금은 모델을 기다리는 동안 계산도 멈춥니다. 이런 방식을 동기식이라고 합니다. 모델의 답변을 기다리는 동안 계산을 계속하는 비동기 방식은 아직 구현하지 않았습니다. 파일 비교는 이번 시험에서 저장 결과가 유지됐는지를 확인한 것입니다. 유체 계산과 모델 해석이 물리적으로 맞는지는 별도로 검증해야 합니다.
