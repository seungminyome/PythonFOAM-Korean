OpenFOAM 계산 관찰하기

PythonFOAM의 PODFoam 예제에 선택형으로 붙인 관찰 기능입니다. OpenFOAM이 도는 동안 Python이 |U|와 p를 이미지로 그리고, 같은 노드에서 도는 이미지 읽는 모델에게 무엇이 보이는지 묻습니다. 답은 기록만 하고, 솔버로 돌려보내지 않습니다. 실행 방법은 README에 있습니다.

최신 보고서 · 11월 3일근거 자료작업 기록

알아낸 것

모델은 따로 적지 않으면 Gemma 4 12B입니다. 모델은 위의 이미지 두 장, 또는 그런 이미지의 짧은 시퀀스와 질문 하나를 받습니다.

영문 저장소의 브랜치 pr/podfoam-fix와 pr/podfoam-observer는 PythonFOAM에 보낼 PR용으로 준비한 브랜치입니다. 두 브랜치는 OpenFOAM v2012, v2106, v2212, 8에서 빌드되고 연결 검증을 통과합니다. 연결 검증은 PODFoam을 10단계 돌려 스냅샷과 POD 모드가 C++와 Python 사이를 오가는 과정을 확인합니다. 두 브랜치는 원본 PODFoam에서 SVD 구간의 첫 스냅샷을 다음 스냅샷이 덮어쓰던 버그도 고칩니다.

주요 수치

답한 자리가 정답 자리에서 표시 영역의 10 % 안에 있으면 맞힌 것입니다. '늘 같은 답'은 모든 이미지에 같은 답을 낼 때의 최고 점수이고, 필드 값으로 만든 간단한 규칙이 더 나았던 시험은 그 규칙도 적었습니다. 모델 넷은 Gemma 4 12B, 26B-A4B, 31B와 Qwen3.5-35B-A3B입니다. 자세한 내용은 보고서마다 있습니다.

한계

  • 시험은 2차원 층류와 압출한 3차원 케이스 하나로 했습니다.
  • 채점한 것은 위치와 정해진 목록의 단어뿐이며, 모델의 설명 글은 채점하지 않았습니다.
  • 병렬 실행은 MPI rank 2개, 동시 요청은 최대 두 개까지 시험했습니다.
  • 두 잘못된 설정 시험은 각각 케이스 하나로 했고, 두 번째 시험은 모델 하나로 했습니다.
  • 모델이 댄 이유는 AI 에이전트 하나가 읽었고, 두 번째 판정자는 없습니다.
  • 다른 GPU에서는 답 문장이 바뀌었지만, 10 % 안에 든 위치의 수는 같았습니다.
