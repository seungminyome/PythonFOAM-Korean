AI에게 어떤 그림을 보여줬나요?

계산한 숫자를 위치에 맞춰 색칠했어요. 날씨 지도에서 기온을 색으로 보는 것과 비슷해요. 이 그림은 속력과 압력을 색으로 보여줘요. 압력은 물이나 공기가 주위를 미는 정도라고 생각하면 돼요.

위쪽 지도 = 얼마나 빠른가?

노란 쪽은 빠르고, 보라 쪽은 느려요. 오른쪽 색 막대는 각 색이 얼마의 속력인지 알려줘요. m/s는 ‘1초에 몇 미터 가는지’를 나타내는 속력의 단위예요.

아래쪽 지도 = 압력 값이 어떤가?

노란 쪽은 압력 관련 값이 크고, 보라 쪽은 작아요. 위쪽과 같은 장소예요. 다만 위는 속력, 아래는 압력 관련 값을 보여줘요.

그림의 기호도 알고 싶어요.

|U|는 속력을 나타내는 기호예요.

x, y는 가로·세로 위치예요. x=0은 기준 위치이고, 그림의 왼쪽 끝을 뜻하지 않아요. 왼쪽 끝은 약 −1.55m, 오른쪽 끝은 약 0.60m예요.

가장 빠른 곳의 속력는 맞게 말했어요. 다만 이 숫자는 글로도 알려줬어요. 그래서 그림을 보고 스스로 알아냈다고 말할 수는 없어요.

틀린 것

가장 빠른 곳이 어디인지는 틀리게 말했어요. 답을 받아오는 기능은 작동했지만, 그 답을 그대로 믿기에는 아직 부족해요.

정확한 위치 숫자와 AI의 원래 표현이 궁금해요.

AI는 “최대속도는 82.5m/s이며, x=0.25m 근처가 빠르다”고 답했어요. 위의 B가 이 위치예요. x는 가로 위치를 뜻해요.

계산한 숫자를 직접 확인한 최대속도는 약 82.5275m/s이고, 위치는 x≈0.000538m예요. 위의 A가 이 위치예요. 둘의 가로 거리는 약 25cm예요.

x=0은 위치를 재기 위해 정한 기준이에요. 통로의 왼쪽 끝은 약 −1.55m, 오른쪽 끝은 약 0.60m라서 A는 그림의 왼쪽 끝에 있지 않아요.

“빠른 곳 옆에 압력이 낮다”는 말은요?

계산한 숫자를 찾아보면 가장 빠른 곳과 압력 값이 가장 작은 곳은 매우 가까워요. 하지만 같은 칸은 아니에요. 이전 설명의 “같은 칸”이라는 문장은 바로잡았어요.

이 문서가 다루는 10월 13일 AI 답은 근처의 “큰 압력 기울기”를 말해요. 이것은 압력이 위치에 따라 많이 변한다는 뜻이에요. 가장 빠른 곳과 압력 값이 가장 작은 곳이 가깝다는 사실만으로는, 압력이 얼마나 급하게 변하는지까지 확인한 것이 아니에요.

이번 두 실행은 그림뿐 아니라 AI에게 준 지시문과 추가 숫자 정보도 달랐어요. 따라서 답변 차이가 그림 하나 때문이라고 단정할 수 없어요. 지금은 “숫자만 보냈을 때도, 그림을 함께 보냈을 때도 답을 받았다”는 것을 확인한 시험이에요.

더 큰 AI를 시험하는 것은 선택지예요. 먼저 현재 방식에서 무엇이 틀리는지 측정하면 다음 선택의 이유가 분명해져요.

“계산 중간에 숫자와 그림을 AI에게 보내고 설명을 받게 만들었어요. 답을 받은 뒤 남은 계산도 끝났고, 저장된 결과도 같았어요. 다만 AI가 위치를 틀리게 말해서, 설명이 얼마나 정확한지는 더 확인하려고 해요.”

다른 자료에 나오는 어려운 말 찾아보기 · 지금은 건너뛰어도 돼요
멀티모달 · Multimodal글과 그림처럼 여러 종류의 자료를 함께 받는 방식이에요. 받는다고 해서 항상 정확히 이해하는 것은 아니에요.
솔버정해진 수학식으로 속력이나 압력 같은 값을 구하는 계산 프로그램이에요.
격자 / 셀복잡한 공간을 계산하기 좋게 나눈 작은 칸이에요. 이 예제에는 20,540개 칸이 있어요.
잔차지금 구한 답을 원래 식에 넣었을 때 얼마나 맞지 않는지 나타내는 숫자예요. 작을수록 식을 더 잘 만족해요. 그래도 실제 현상까지 정확하다는 뜻은 아니에요.
Courant 수한 단계 동안 흐름이 작은 칸의 크기에 비해 얼마나 이동하는지 나타내는 숫자예요. 시간을 너무 크게 건너뛰며 계산하지 않는지 살필 때 써요. 알맞은 크기는 계산법에 따라 달라요.
SVD / PODSVD = Singular Value Decomposition(특이값 분해)예요. 숫자 표를 큰 패턴과 크기로 나눠 보는 계산이에요. POD = Proper Orthogonal Decomposition(고유직교분해)는 여러 시점에서 대표 패턴을 뽑는 방법이에요. 이번에는 SVD로 속도 자료를 요약해 AI에게 줬어요. 높은 패턴 비율은 AI의 정확도가 아니에요.
양자화 Q4_0AI 내부의 숫자를 더 적은 저장 공간에 담는 방식이에요. 컴퓨터의 기억 공간을 덜 쓰지만 답이 얼마나 정확한지는 따로 확인해야 해요.
JSON / 해시JSON = JavaScript Object Notation, 이름표를 붙여 적는 자료 형식이에요. 해시는 파일의 지문처럼 변경 여부나 복사 일치를 확인할 때 써요.
in-situ여기서는 계산이 끝난 뒤가 아니라, 계산하는 도중에 상태를 확인한다는 뜻이에요.
로컬 모델내 컴퓨터에서 돌아가는 AI예요. 이번에는 같은 컴퓨터 안의 AI에게 자료를 보내 답을 받았어요.
